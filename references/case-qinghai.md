# 实战复盘：青海《工程造价管理信息》双月刊 PDF → 16.7 万条结构化数据

40 期双月刊、8 期转曲刊 OCR 补全、修复 10 个版式类 Bug 后全量终检通过。
本文记录每类 Bug 的症状 → 机制 → 修法，供同类"连续出版物表格 PDF"项目对照排查。

## 项目概况

- 源：《青海工程造价管理信息》双月刊（政府站下载，其中 1 期是原始文件名 P02026...pdf）
- 目标：纯前端查询系统（data/*.js + index.json + trends.js）
- 工具链：PyMuPDF 文本层抽取（装在项目 vendor/ 随目录走）+ RapidOCR（转曲刊兜底，页缓存可删可重建）
- 数据规模：40 期 / 581,108 价格点 / 7,684 材料 / 43 地区

## 十个 Bug 的症状→机制→修法

| # | 症状 | 机制 | 修法 |
|---|------|------|------|
| ① | 表格行序错乱 | 同一印刷行多个词的 y 取平均后跨列重排 | 行带（band）按数值行 y 聚类，逐行取带内文本 |
| ② | 价格粘列 | 县名列缺失时价格词 x 落入邻列 | 丢远离列中心(>25pt)的盒子；含≥2汉字的盒子不作价格 |
| ③ | 跨页表格右半页丢失 | 右半页仅价格列无表头 | 按行 y 坐标最近邻(≤6pt)配对合并进左页 |
| ④ | 分组行错位 | 有色/木材等分组行右半页无对应行 | 配对时按分组词表跳过 |
| ⑤ | 页眉污染 kind 判定 | "·指导价格·"页眉含价格关键字 | kind 判定跳过短页眉行 |
| ⑥ | 县名列全空→塌缩成"XX地区"伪列 | OCR 碎片行（"单位"竖排拆出"单"）中断表头向上收集 | 表头收集跳碎片行（≤2字无数字非关键字，最多跳1行） |
| ⑦ | "XX地区"伪列吞掉 6 个县的价格 | area=None 的价格列被 `area or default_area` 塌缩，同槽位互相覆盖只剩最后一列 | **防线：无县名且匿名价格列≥3 → 拒绝整页**；**代码里禁写 `area or default` 这种兜底** |
| ⑧ | 新版式 B 页整页丢失 | r0 无关键字被误判成旧版式 | unpaired 表转"仅价格列"表按页序插回参与配对 |
| ⑨ | 单县名行版式整页被防线误杀 | 防线阈值过狠（县名≥2 才收集） | 阈值放宽到 ≥1，防线只在"零县名+多匿名价格列"时触发 |
| ⑩ | 拼行双价污染 32 行 | 同 (blk,ln) 两价格词粘连 '350.00350(茶卡398)' 落单列，垃圾行混入表头 → 列升格塌缩 | 双价拆分正则（见下）+ 表头 hs 过滤数字行 |

## 拼行双价拆分的正则细节（Bug ⑩，最容易做错）

目标：`'350.00350(茶卡398)'` → 主价 `350.00` + 括注价 `350`（括注是镇级参考价，模型无法表达则剥除）。

```python
# 错误：group1 贪婪回溯 → '350.0035'/'0'
SPLIT2_RE = re.compile(r"^([\d,.]+)(\d[\d,.]*[(（][^)）]*[)）])$")
# 正确：group1 限定「整数+恰好两位小数」完整价格形态；'60.00（茶卡）'（括注无价）不匹配
SPLIT2_RE = re.compile(r"^(\d[\d,]*\.\d{2})(\d+[(（][^)）]*[)）])$")
```

附加保险：**右列该行 y 附近已有数字则不拆**（拼接未发生时防破坏正常行）。

## 原件层面的坑（与代码无关但必踩）

1. **原件印刷错误**：22 期劳务表印「天骏」（正确为天峻），机械表却印「天峻」——
   需 CountyFix 映射归一，且须先与原件逐字核对确认是印刷错误再修。
2. **反常数值是原件本身**：C45 德令哈 510 > 乌兰 490，与相邻行规律相反——
   用 words 按 y 聚集逐字比对原件确认后**保留**，不要"顺手修正"。
3. **前后页写法不一致**：格尔木 vs 格尔木(唐古拉镇)、海晏县 vs 海晏县(含西海镇)——
   列名归一化统一剥括注（同时消除列分裂风险）。
4. **表题只在附件首页**，续页无表题 → 跨页解析要维护"当前地区"状态。
5. **单地区统一价表是合法形态**：西宁/海北等早期版式整个表就一个价格列，
   area='XX地区' 不是伪列。真伪列判据 = 地区列与县列**共存**，或"该地区本该是
   县列表却只有地区列"。体检一刀切会误报 284 处。
6. **政府站原始文件名 PDF**（P020260902619683658372.pdf）glob 标准命名抓不到 →
   期号用正文"总第N期"回退解析。

## 交付前体检清单

1. 全量伪列共现扫描（区分合法/塌缩）

5. 增量更新的 glob 名单要涵盖非标准命名的源文件

## 环境要点

- PyMuPDF 用 `pip install --target vendor/` 装进项目，随目录拷贝可用；
  find_tables 每页打 "Consider using pymupdf_layout" 噪音，grep 过滤
- OCR（RapidOCR）装独立 venv，页级 JSON 缓存（可删，命中后重建很快）
- Windows 下 Bash 需要 `export PATH="/usr/bin:/bin:$PATH"` 前缀，多行 python -c
  在部分 shell 里有引号坑 → 探针一律写独立 .py 文件执行
